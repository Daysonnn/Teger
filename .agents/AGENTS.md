# Agent Rules for Interface, UI, Typography, Colors & Accessibility

Always apply the principles from the following skills across all UI, frontend, and Mini App components:

- **better-interface**: Systemic, holistic cross-discipline interface review and design standards.
- **better-ui**: Details that make interfaces feel polished (concentric border radius, optical alignment, layered shadows, scale-on-press 0.96, proper motion restraint, interruptible transitions).
- **better-typography**: Professional typography (WOFF2, tabular-nums for changing values, unitless line-heights, 16px mobile inputs, balanced headings).
- **better-colors**: Perceptually uniform color management (OKLCH, high contrast ratios, semantic token usage, light/dark mode harmony).
- **better-accessibility**: High-craft accessibility (native HTML elements, visible `:focus-visible` rings, minimum target sizes, ARIA labels, keyboard navigation, reduced-motion support).
